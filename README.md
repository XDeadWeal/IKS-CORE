# IKS-CORE

**A monolithic programming language built to challenge Rust and C++.**

IKS-CORE is a new monolithic programming language designed from the ground up to compete with Rust and C++. It is no longer just a graphics backend — it is a full programming language with its own native CPU and GPU backends, first-class graphics support, and hardware-aware acceleration detection built directly into the core.

## Highlights

- **Monolithic language design** — a single, cohesive language core instead of a pile of disconnected tooling.
- **Native CPU and GPU backends** — IKS-CORE ships with its own backends for both CPU and GPU execution.
- **Six graphics APIs out of the box** — native support for DirectX 9, DirectX 10, DirectX 11, DirectX 12, Vulkan, and OpenGL/OpenGL ES.
- **Built-in NPU autodetection** — AI accelerators are detected directly in the language core, not bolted on as an afterthought.
- **Hardware-aware by default** — the language is designed to understand the machine it runs on.
- **Built to take on Rust and C++** — IKS-CORE aims to compete with the current systems-programming establishment on performance, control, and portability.

## Why IKS-CORE?

Most languages today are assembled from separate pieces: a compiler here, a graphics layer there, a hardware-detection library somewhere else. IKS-CORE takes a different approach — one monolithic language core with native CPU/GPU backends, native graphics API support, and NPU autodetection integrated from the start.
